# Worst AI Advice: The 48-Hour Tight Line Open

One line of the worst possible advice an AI could give — a confident "Pro tip" that tells you to turn up the radio when your brakes squeal, because if you can't hear the problem, it isn't a problem. Concrete, followable, and regrettable: the brakes are still failing, you just can't hear them anymore.

The program validates the 1–140 character gate before writing, writes the line to `/output/entry.txt`, then reads it back and verifies it.

## Run it

```sh
node main.ts
```

Requires Node 22.18+ (no dependencies, `node:fs` only). The line is written to `/output/entry.txt`.
